# Carbon fiber electrode arrays (University of Michigan)

The 2015 and 2020 arrays are related but use different supports, exposed sites, acquisition and targets. Every measurement below belongs to its named configuration or cohort. Unreported means not established by the reviewed primary papers.

## Identity

| Field | Value and source scope |
| --- | --- |
| Device | Michigan carbon-fiber arrays: 2015 PEG/silicon-supported arrays and 2020 flex multimodal configuration |
| Manufacturer | Chestek-led academic fabrication, not commercial clinical system |
| Interface class | Penetrating fiber recording array; 2020 configuration adds FSCV chemical sensing |
| Origin | University of Michigan researchers and collaborators; configurations attributed to Patel et al. 2015/2020 |
| First demonstrated | 2015 linear-array paper; earlier individual carbon-fiber work not claimed as new here |
| First human implant | Unreported; reviewed experiments are rodents |
| Species studied | Long-Evans rats; ex vivo rat brains and agarose insertion tests separate |
| Regulatory status | Preclinical research under Michigan animal approvals; no human clearance established |
| Function | 2015 single-unit recording; 2020 flex unit recording plus dopamine FSCV in separate sessions |
| Target tissue | 2015 rat motor cortex; 2020 nucleus accumbens core/shell target, actual core/anterior commissure localization |

## Geometry and architecture

| Field | Value and source scope |
| --- | --- |
| Interface type | Individual penetrating carbon fibers with temporary PEG stiffening or permanent silicon supports; 2020 glass-cannula-supported flex array |
| Array layout | 2015 two PCB faces, eight traces each; silicon 8-shank supports/three-layer stack. 2020 flex 2 x 8 |
| Electrode count | Nominal 16 channels; 2015 chronic 60 implanted fibers vs 80 theoretical across five animals. 2015 acute silicon only alternate shanks populated; three-layer 12 sites but four wired. 2020 flex 16 |
| Pitch | 2015 PCB specified 152.4 µm, measured 153.7±1 µm (SEM, n=50 distances). Silicon supports 150 µm but alternate shank population gives 300 µm contact spacing. 2020 flex 132 µm; test PCB 152 µm |
| Electrode lengths | 2015 chronic fibers 4-5 mm overall, PEG leaves about 500 µm exposed per insertion step. Silicon supports 750/1000 µm plus 500 µm projecting fiber. 2020 implanted flex fibers 500 µm beyond glass cannula |
| Shank width and thickness | Carbon core 6.8 µm plus 800 nm radial Parylene C gives 8.4 µm outer diameter. Silicon supports maximum about 30 µm width, about 12 µm silicon below 10 µm-deep groove. 2020 flex PCB 100 µm polyimide |
| Tip and exposed site geometry | 2015 cut fiber end coated PEDOT:pTS. 2020 laser exposes 50 or 100 µm carbon length then plasma ashes; 50 µm chosen in vivo |
| Contact coating | 2015 PEDOT:pTS; 2020 exposed/plasma-ashed bare carbon, not same coating |
| Insulation | 800 nm Parylene C; insulating epoxy covers fiber/trace joint |
| Insertion method | 2015 staged PEG dissolution/insertion over about 15-20 min or silicon guide. 2020 flex placed through implanted glass cannula to accumbens, no PEG-coated fiber column retained |
| Anchoring and fixation | 2015 skull screws/dental acrylic with Kwik-Cast or alginate around exposed fibers; 2020 cannula and flex array cemented, protective tube around head connectors |

## Electrode and channel physics

| Field | Value and source scope |
| --- | --- |
| Exposed site area | 2015 nominal carbon cut-end 36.3 µm² used for CSC calculations. 2020 sidewall exposure 50/100 µm is distinct, not assigned cut-end area |
| Electrode material | Carbon fiber; 2015 PEDOT:pTS lowers site impedance; 2020 laser/plasma-prepared carbon |
| Impedance (with measurement frequency) | 2015 accelerated saline soak n=23: PEDOT 118±28 kΩ at 1 kHz day 0, 321±56 kΩ simulated day 29.5 (SEM), not in vivo. 2020 flex saline 50 µm exposure 370±61 kΩ n=75, 100 µm 225±105 kΩ n=57 (SD) |
| Noise floor or SNR | 2015 planar silicon-supported 16 units mean amplitude 245.9±122.2 µV (SD), not noise floor. Numerical RMS floor unreported here; 2020 reports small spikes |
| Recording modality | 2015 extracellular units; 2020 units plus FSCV dopamine in separate sessions, not simultaneously from a single headstage |
| Sampling rate | 2015 approximately 25 kHz TDT; 2020 electrophysiology 30 kHz Intan. FSCV scan waveform parameters not substituted for digitizer rate |
| Stimulation capability | Array records; 2020 dopamine elicitation uses separate implanted VTA steel stimulating electrode, not a carbon-array stimulation demonstration |
| Charge injection limit | Unreported; CSC/voltammetry measurements are not stimulation charge-injection limits |
| Reference and ground | 2015 PCB reference/ground at posterior skull screw. 2020 electrophysiology screw over cerebellum plus common-average reference in analysis; FSCV separate Ag/AgCl wire in cannula |

## Tissue interface and bioresponse

| Field | Value and source scope |
| --- | --- |
| Target tissue | Penetrating motor cortex or nucleus accumbens, configuration-specific |
| Insertion trauma and BBB disruption | Fiber footprint small but cranial access/dural resection or deep glass-cannula insertion remain invasive. 2015 blunt silicon predecessor dimpling 150.5±41.4 µm vs pointed 33.0±11.6 µm (SD, six shanks each, 650 µm insertion). 2020 cannula damage envelope excludes 14 identified electrodes/holes with white-matter exclusions combined |
| Vascular disruption risk | 2015 fibers deliberately removed if path crossed major surface vessel; quantitative bleeding rate unreported |
| Micromotion sensitivity | Small compliant fibers proposed to reduce tissue strain; skull-attached PCB/cannula remain. No numerical chronic motion-transfer metric |
| Gliosis and encapsulation | 2020 neuron-density study does not supply numerical astrocyte/microglia burden for this sheet; do not import earlier single-fiber results |
| Neuron loss near sites | 2020 four-rat histology at 10.1-13.3 weeks: 58/64 fibers/holes localized, 44 analyzed after 14 exclusions. Density 25-100 µm from sites not significantly different from 175-200 µm reference, excluding cannula-damage/white-matter regions |
| Foreign-body response mitigation | 8.4 µm insulated fiber diameter; small footprint is rationale, not proof of universal absence of damage |
| Typical failure modes | 2015 fabrication/insertion breakage, fiber sticking, vessel avoidance, missed PEDOT and broken channel. 2020 silver-epoxy shorts, fiber breaks, inadequate laser exposure/high impedance/noisy dopamine channels |

## Performance envelope

| Field | Value and source scope |
| --- | --- |
| Acute yield | 2015 silicon planar: 16 distinct units on nine/ten functionalized channels across two rats; stacked prototype four of 12 available sites wired. 2020 bench electrical yield 94% for 50 µm, 89% for 100 µm; flow-cell usable yield 84%/70%, not implant survival |
| Chronic yield | 2015 all five chronic rats show unit activity, 60/80 nominal fibers implanted. 2020 one recording rat: dopamine detected 11 channels, units seven channels at day 34; do not equate channel detection with lifetime yield |
| Stability over time | 2015 representative recordings days 1 and 31. 2020 dopamine/unit same-day different sessions day 34, not continuous dual-modal monitoring |
| Longevity | 2015 day-31 recordings. 2020 day-34 functional demonstration, recording rat sacrificed day 78, separate 10.1-13.3-week histology; terminal tissue duration not a recording-duration claim |
| Revision and explant experience | 2020 terminal perfusion and sectioning with implanted fibers/cannula left in place for anatomical localization; no clinical revision series |
| Adverse events | 2015 damaged/missing channels; 2020 substantial cannula tissue damage in one histology animal and excluded regions. No standardized clinical adverse-event rate |
| Notable demonstrations | Thin fiber arrays inserted densely; 2020 unit/dopamine sensing on same array in separate sessions with postmortem channel-level anatomical localization |

## Clinical and preclinical evidence

| Field | Value and source scope |
| --- | --- |
| Human subjects | None in reviewed 2015/2020 studies |
| Preclinical cohort | 2015 chronic PEG five rats; planar silicon recordings two rats, stacked recording one rat and separate insertion demonstration. 2020 recording one rat plus four separate histology rats; bench fiber counts not subjects |
| Follow-up duration | 2015 31 days functional; 2020 34 days functional, terminal recording-animal tissue day 78 and separate histology 10.1-13.3 weeks |
| Indications | Preclinical extracellular/chemical research, not approved BCI treatment |
| Trials and registries | Animal ethics approvals, no human registry established |
| Primary outcomes | Insertion reliability, electrophysiology, impedance, dopamine calibration/detection and precise histological neuron density/localization |
| Key limitations | Distinct coatings/geometries and targets; 2020 one functional animal, day-15 natural dopamine observation lacks control data. Tissue exclusions limit generalization; prior year-long carbon-fiber work is another technology, not this array |

## Engineering tradeoffs

| Field | Value and source scope |
| --- | --- |
| Strengths | Small individual footprint, recording/chemical versatility and tissue sectioning with electrodes in place |
| Limitations | Manual fabrication/connection, breakage and channel-yield loss; insertion supports/cannula can dominate damage |
| Scaling constraints | Dense wiring and manual placement limit throughput; 2015 nominal site count exceeds actual wired stack sites, 2020 higher density not automatically higher functional yield |
