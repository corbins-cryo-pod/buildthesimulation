# Neuropixels engineering package

Integrated 2026-10-25 from the original neuropixels-3d-model-package.zip.

The complete extracted package is preserved byte-for-byte under
public/models/neuropixels-engineering, including its original SHA-256 manifest,
viewer, model assets, drawings, source and validation reports. A TAR.XZ archive containing the same 56 byte-identical files
is provided for download; the original ZIP exceeded the GitHub app transfer limit. Do not regenerate or replace this package with
the simpler catalog model exporter.

Entry points:
- /devices/04-neuropixels-probe/#engineering-model
- /models/neuropixels-engineering/neuropixels-3d-viewer.html
- /devices/models/

The embedded viewer loads only after its disclosure is opened. The full-screen
and downloadable offline viewer are the original self-contained HTML. Original
model selection and camera defaults are intentionally preserved.

Integration checks: source manifest checksums, byte comparison of all 56 extracted
files, binary GLB headers and lengths, all component asset links, and Astro build
(525 pages) passed. Original browser reports describe the original package run;
a fresh local browser test could not run because Chromium installation failed.

Nominal shank dimensions and site layout are distinguished from reconstructed
connector details and illustrative pore morphology in both the page and viewer.
