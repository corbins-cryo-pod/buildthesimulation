# Studio presentation standard

The Neural Interface Studio follows the shared simulation-laboratory
presentation standard (the SimHero masthead component, introduced site-wide
in #355):

- `/simulations/neural-interface-studio/` opens with the standard masthead:
  kicker "Design & microfabrication / Digital cleanroom", spaced-cap title,
  italic intro, and a links column pointing to the process model and the
  Designer-to-cleanroom handoff. A family strip links the Studio with the
  Neural Interface Designer.
- `/simulations/neural-interface-studio/handoff/` uses the same masthead
  with kicker "Neural Interface Studio / Stage 2.1".
- The methods page keeps its long-form article layout, matching the other
  laboratories' methods pages.

The Studio engine, cleanroom model and transfer pipeline are unchanged;
the standard covers page chrome only.
