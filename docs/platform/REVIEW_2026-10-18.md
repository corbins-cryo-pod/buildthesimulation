# BuildTheSimulation: the integrated laboratory and the next scientific platform

**Review date:** October 18, 2026, America/New_York; work continued October 19 UTC.

**Inspected implementation:** `4a15be0ca29bef6c1c6a963cb311b52ba8f34ba8`.

**Live laboratory:** <https://buildthesimulation.com/cortex/interface/>.

**Purpose:** a comprehensive source-based assessment and development plan following the first integrated twelve-cell interface laboratory. Recommendations below are proposed work, not claims of completed features.

## 1. The central judgment

The new laboratory establishes the right center of gravity for this website. A physical contact layout, individual human source models, extracellular stimulation, compartment membrane dynamics, and ideal extracellular recordings now participate in one calculation. The membrane colors come from computed voltages throughout the cells. The recordings come from the cells' computed membrane currents. The stimulation and recording operators use the same reciprocal contact model. This connection is the achievement to preserve.

The next major advance should be **a reproducible experiment that explains a design trade-off**. A visitor should be able to choose a sourced cell set, load an interface, reproduce a baseline, change one design variable, inspect the membrane and recording consequences, and reopen the exact comparison later. The site already contains much of the intellectual and technical material needed. It needs a shared experimental structure, carefully extended physics, and evidence that follows each result.

Three findings determine the order of work:

1. **The finite contacts are electrically modeled; the finite shank body is not yet electrically modeled.** The current eight-pad solve uses an infinite insulating plane with tissue on one side. The visible tip, shaft edges, thickness, and backside do not enter that solve. A true finite-body conductor is necessary for questions about those features.
2. **The current recordings are ideal source signals, not a complete instrument's output.** The saved evoked example contains a modeled direct terminal excursion of approximately 5.034 V at its active pad, beside a membrane-source peak of approximately 44.1 µV. This is a concrete reason to model delivery, reference, saturation, recovery, filtering, and noise before claiming that evoked spikes would be recoverable in hardware.
3. **Geometry comparisons must preserve the underlying experiment.** Different pad sizes currently occupy different locations. Several older simulations also contain direct comparison defects. These should be corrected before a design ranking or optimization is offered.

None of these findings erases the working integration. They identify the next boundary between an inspectable computational demonstration and a defensible engineering experiment. The best development strategy is to finish that chain for twelve cells and a small set of contacts, then expand its breadth.

The review distinguishes four kinds of statements: **observed implementation**, **measured numerical result**, **interpretation within declared assumptions**, and **proposed capability**. A source comment is evidence of intended scope, not independent verification of the equation. A passing algebraic identity is useful numerical evidence, not a biological validation. A realistic rendering is a view of a model, not evidence for its unmodeled physics.

The completed interface implementation passed 20 focused tests, an Astro build producing 469 pages, the existing Cortex build verifier, and a successful Cloudflare deployment. These checks preceded this review. The verifier currently targets the original Cortex route more fully than the new interface, which is itself a finding. Browser interaction and visual QA were **not performed**: the supported browser-control capability was unavailable in this managed environment, and the Sites workflow explicitly requires skipping browser QA in that situation. Static inspection and Node checks are not substituted for browser evidence.

The inventory covers every identified simulation family and its live implementation. It does not mean that every catalog source paper, every possible parameter combination, or every interaction was independently reproduced. No new broad calibration sweep was run during this audit. Small deterministic diagnostics and decoding of existing archives supplied the new measurements described below. Detailed appendices retain their own diagnostic conditions; different diagnostic settings can produce different event counts while demonstrating the same defect.

## 3. What has actually been built

The default interface contains twelve distinct source specimens and 3,428 electrical compartments. It uses the original active cable and fitted channel machinery. Whole morphologies are placed rigidly; they are not stretched into convenient shapes. Each compartment has a computed membrane voltage, and all cells use one voltage palette. A cell without a somatic event remains a solved cell with inspectable membrane behavior.

The hypothetical shank is 90 µm wide, 20 µm thick, and 1,800 µm long, with a 300 µm pointed tip. Eight surface contacts alternate between 12 × 12, 20 × 20, 30 × 30, and 12 × 24 µm dimensions. It is inspired by slender silicon probes, including Neuropixels, but it is an independently specified test geometry. It is not a replica, a fabricated device, or an optimized design derived from all catalog entries.

The contact solution includes all eight ideal equipotential pads jointly. Unselected pads float with zero net current; their induced local surface currents remain part of the solution. This is more physically meaningful than treating each selected pad as an unrelated point source. The same unit-current fields drive the cells and project membrane currents back to the contacts.

The default ongoing-firing example uses explicit constant somatic current injection, calibrated separately for each source cell. It produces 164 complete somatic events in its 260 ms solved window. Playback repeats that window at approximately eight biological milliseconds per wall-clock second. It is a slow replay of a finite computation, not an indefinitely evolving network. Its repeating cells are independent, driven test specimens, not a model of spontaneous cortical circuit activity.

The saved evoked example uses zero somatic drive, two charge-balanced pulse events within 100 ms, and contact 5 at 40 µA with 200 µs phases. Specimen 601927090 produces two complete somatic events, at approximately 20.871 and 70.794 ms. The other eleven cells produce no complete soma event under the implemented criterion. All cells remain electrically modeled. This is evidence of that exact computational response; it does not establish a converged threshold, axonal delivery, or biological selectivity.

The detector requires an upward −25 mV crossing, a peak reaching at least 0 mV within 3 ms, recovery below −40 mV within 20 ms, and a refractory condition. That is stronger than calling every threshold crossing a spike. Its definition must remain visible, especially when compared with other pages that use different criteria.

Integration uses 0.005 ms steps and a 40 µm cable discretization setting. Saved visualization samples are 0.1 ms apart. The default archived compartment voltages are rounded to 0.01 mV, then reversibly delta-encoded and compressed. This visual-storage precision does not alter the separately computed events or recording arrays. The default compressed replay is approximately 11.06 MB; its decoded Float32 voltage array alone is approximately 35.66 MB. These are useful, inspectable artifacts, but their size also motivates progressive loading and explicit memory budgets.

Implementation and retained calibration evidence are documented in [the interface methods record](../cortex/INTERFACE_LABORATORY.md) and [cell preset report](../cortex/INTERFACE_CELL_PRESETS.md).

## 5. Scientific integrity: preserve the good foundations and close the consequential gaps

### 5.1 Preserve source identity and the original electrical model

The imported human models retain source identity, fitted conductances, temperature conventions, morphology handling, and native-derived electrical geometry. The tree solve and membrane-current accounting are valuable infrastructure. Existing numerical reports retain failures rather than concealing them. These practices should become platform-wide requirements.

The model library is not a complete cortical census. It contains fourteen human EAP specimens and two epilepsy-project basket-cell adaptations. The latter use an available reconstruction of the same specimen because the exact historical morphology revision is unavailable. The default twelve are a useful subset selected partly for repeated firing and practical computation. They are not representative of every layer, region, disease state, or cell class. Excitatory/inhibitory labels do not create a functioning network without defined synapses.

The original EAP modeling convention replaces the reconstructed axon with two 30 µm sections. Reproducing this is faithful to the source. It also limits claims about extracellular recruitment, passing fibers, myelinated axons, and distal spike delivery. A separate stimulation-oriented model family should add full or repaired axons with explicit provenance, followed by renewed passive, firing, conduction, and strength–duration characterization. Never silently modify the original fit and inherit its old evidence. Published stimulation modeling demonstrates why axon branching, diameter, and myelination need explicit treatment; it does not validate an untested adaptation here [P3].

### 5.2 Separate three kinds of validation

**Implementation agreement** asks whether independent implementations solve the same discretized problem. **Numerical convergence** asks whether the conclusion stabilizes when discretization changes. **Experimental validation** asks whether the model predicts relevant measurements. A badge saying only “validated” cannot communicate these differences.

The original studies contain close native-NEURON agreement alongside unresolved mesh-sensitive events. The finite-disk work retains a roughly 21–22% coarse-to-intermediate local-onset shift despite close matched implementation agreement. The new twelve-cell calibration retains repeated complete events at 40 and 20 µm, but spike counts and timing are not invariant; an ordinal-event timing difference reaches 37.134 ms. Eleven final-current configurations have half-timestep persistence checks; the revised current for specimen 508378649 does not yet have that check. These facts support a useful calibrated demonstration, not a claim of converged natural firing statistics.

The next numerical campaign should be bounded and predeclared: selected cells and placements, baseline and evoked protocols, fixed physical observation locations, independent native dynamics, field refinement, cable refinement, and timestep refinement. Compare waveforms, currents, onset/loss brackets, and event classification. Keep failed cases. Do not loosen tolerances after seeing outcomes or alter conductances simply to make a numerical gate pass.

A threshold search must allow nonmonotonic behavior such as block or competing initiation sites. A bisection tolerance alone is not a physical uncertainty interval. Preserve regions where event classification changes with resolution and explicitly mark censored events near the end of the recording window.

### 5.3 Validate the field quantities that actually drive a cable

The contact solver's algebraic current balance, equipotential constraints, and reciprocity checks are necessary. They are not a complete field-error estimate. In particular, the membrane solver responds to extracellular potential differences along electrical edges, multiplied by axial conductance. Small errors in large absolute potentials can leave substantial error in their small difference.

For actual cell placements, compare the potential with a declared reference, every edge's potential difference, the assembled forcing vector, terminal transfer coefficients, and source-integrated recording coefficients. Use absolute tolerances when a reference value approaches zero. Include off-quadrature checks of surface potential and insulation, common-mode invariance, and independent field solutions. A symmetrized matrix passing reciprocity confirms a construction property; an independently assembled comparison adds different evidence.

The current recording approximation concentrates each compartment's membrane current at its center. Near small contacts or long curved segments, introduce area-weighted line/polyline integration of the reciprocal field, preserving total compartment current and declaring the assumed distribution over a tapered segment. Quantify the difference from the center approximation. A finer-looking rendered branch cannot improve a coarse electrical source representation.

### 5.4 Make the finite shank physically consequential

The next conductor should use one geometry document to generate a watertight insulating body and tagged conductive patches. Tissue must be supported around front, back, sides, and tip. Returns need explicit geometry or a justified remote-boundary approximation. Contact behavior, conductivity, and boundary conditions must be part of the result record.

Retain the plane solve as a benchmark. Demonstrate its limiting case, identify regions where it approximates the finite body acceptably, and map where it does not. Add current balance, gauge, reciprocity, surface residual, mesh, outer-domain, and independent solver tests. The scientific output should include an approximation-error map around the shaft, not merely a different field visualization. Probe-presence modeling in the literature motivates this comparison [P1].

Mechanical questions belong to an additional model. A long pointed tip may be a useful design feature, but the current simulation cannot predict insertion force, buckling, tissue displacement, injury, or chronic response. A future mechanics layer should expose those quantities and its own material and tissue evidence. Electrical optimization cannot silently stand in for mechanical feasibility.

### 5.5 Complete the path from a commanded pulse to an observed signal

The most concrete engineering warning in this review comes from the existing saved evoked data, not from a hypothetical scenario:

| Contact | Maximum absolute membrane-source potential, µV | Maximum absolute ideal direct applied potential, mV |
| --- | ---: | ---: |
| 1 | 0.507 | 31.213 |
| 2 | 0.109 | 41.524 |
| 3 | 1.466 | 62.452 |
| 4 | 11.072 | 122.335 |
| 5, active | 44.098 | 5,034.407 |
| 6 | 3.601 | 122.213 |
| 7 | 3.727 | 62.450 |
| 8 | 2.287 | 41.529 |

The membrane-source column includes stimulus-driven capacitive and ionic currents; it is not an isolated spike amplitude. The applied column is the ideal resistive model term, not a hardware measurement or an already modeled amplifier output. At 40 µA for 200 µs, a phase carries 8 nC. Contact 5 has 144 µm² geometric area, giving approximately 5.56 mC/cm² geometric average charge density per phase. This is an accounting calculation, not a material charge-injection limit or a safety verdict.

The missing questions are now precise: can a specified driver deliver that current with the required voltage? What electrode polarization results? How does a chosen reference transform the channels? Does the front end clip? When does it recover? Which early evoked events remain measurable? A clean numerically separated neural trace cannot answer these questions. Saturation can remove information before digital artifact subtraction.

For scale only, the Neuropixels 2.0 publication reports a 12.5 mV peak-to-peak input range, 30 kHz sampling, and 14-bit resolution [P2]. This test shank has not selected that hardware. Its specifications must not be assigned by resemblance. The comparison simply shows why acquisition cannot be omitted from a serious recording-and-stimulation design study.

Build the chain in explicit stages: command; delivered current after compliance; metal and tissue potentials; electrode polarization; reference-subtracted mixed voltage; analog filtering; saturation/recovery; ADC; detection; optional sorting. Retain ideal source signals as ground truth. Parameterize interfaces from suitable impedance and pulse-transient data, keeping assumptions and applicability visible. Charge balance alone is not evidence of deliverability.

The reduced stimulation laboratory has useful interface/compliance interaction concepts, but it solves a different full-space uniform-source problem. Reuse its concepts and relevant tests after adaptation. Do not copy its access resistance, exposed-area convention, illustrative material parameters, or validation status into the one-sided equipotential model.

### 5.6 Separate actual cellular events from detected recording events

The current raster represents known modeled soma events. A future detected raster must be produced from the acquired mixed channels, without access to hidden source labels during detection. Evaluate precision, recall, timing error, overlap failures, and false positives against the retained source truth. Sorting benchmarks such as SpikeInterface provide useful methods and interoperable outputs [P4].

Use a shared event vocabulary: local crossing, complete somatic waveform, censored waveform, axonal event, propagation assessment, synthetic source event, measured threshold count, and detected extracellular event. Store the criterion and version. Invalid numerical trajectories must have their own state; they are neither valid recruited cells nor biologically silent cells.

For combined ongoing firing and stimulation, use a paired no-stimulation control with identical initial states and background realization. Classify added, lost, advanced, and delayed events using a declared matching method. A pulse can change timing without changing count. A traveling voltage color pattern is useful for inspection, but a propagation claim needs branch-connected timing, current evidence, post-stimulus behavior, and appropriate interventions that distinguish local forcing from regenerative transmission.

### 5.7 Make tissue, background, and coupling assumptions explicit

The present interface uses a homogeneous isotropic conductor and one-way coupling: applied contact fields affect the cells, and their membrane currents generate ideal recordings, but those generated extracellular fields do not feed back onto neighboring cells or the same cell. There are no synapses or ephaptic interactions. This is a useful, computationally tractable test bench; proximity in the scene does not establish electrical communication between neurons.

Tissue heterogeneity, anisotropy, encapsulation, and frequency-dependent properties should enter as separate versioned conductor capabilities when the intended experiment requires them. Each needs appropriate parameter evidence and independent verification. A conductivity slider alone cannot represent all of these effects. Begin with sensitivity ranges justified by the intended tissue and experiment, then add structural complexity where it changes a decision. Keep geometry, conductivity, interface impedance, and neural excitability uncertainty separate so one can see which assumption dominates a result.

The imposed patch-style drive also has a return-path assumption. The summed outward membrane current reflects injected current, and the existing implementation correctly avoids adding that injection a second time. It does not explicitly represent a nearby patch electrode and its bath return. State that boundary in the experiment record, retain raw signals, and distinguish a display's mean subtraction from an actual recording filter. A future calibration against a patch experiment must match its stimulation and recording circuit rather than only its soma waveform.

## 6. Turn the device collection into usable experimental knowledge

The catalog is substantial, but its layers of readiness differ:

| Repository inventory | Count | What it establishes |
| --- | ---: | --- |
| Published device/design briefs | 142 | Referenced descriptions across multiple implant classes |
| Dimensioned geometry configurations | 36 | Selected structured geometries, with varying fidelity |
| Site entries across exported configurations | 28,372 | Exported records, not unique physical implants or independently validated contacts |
| Site records with unknown exposed area | 1,794 | Explicitly retained missing information |
| Structured geometry fidelity ledgers | 23 | More formal evidence and assumption records |
| Existing Cortex device adapters | 3 | Utah, one N1 thread, and one Neuropixels 1.0 shank, with scoped support |

The published briefs include 47 intracortical, 28 ECoG, and 27 peripheral devices, plus spinal, deep-brain, cochlear, endovascular, retinal, brainstem, sensing, and other designs. This breadth is a research asset. It does not mean 142 stimulation-ready digital twins are available. Study-stage labels such as human or preclinical do not certify reconstructed geometry or regulatory status.

Create a versioned device experiment contract containing local frame, units, body surfaces, exposed contact surfaces, stable site IDs, surface orientation, material/interface references, physical-site versus hardware-channel mapping, bank/switch constraints, and evidence for each parameter. Keep reported, derived, inferred, modeled, and unknown values distinct. A ring may need distributed normals; a tip coordinate is not a recovered exposed surface. Unknown area must stay unknown until a sourced value or an explicitly hypothetical derivative is supplied.

The designer should initially export only shapes the target solver actually supports. A planar rectangle layout can enter the current plane solver after unit, pose, orientation, nonoverlap, and domain checks. A wrapped cuff or curved contact cannot be silently flattened into that solver. The rendered geometry and numerical boundary should derive from the same document, with any approximation represented explicitly.

Preserve source variants. For example, the research Neuropixels geometry and a later manufacturer's variant may differ. A current datasheet must not silently change an older saved experiment. The original Neuropixels publication establishes an important slender, dense recording-probe precedent [P5]; it does not establish that a similar-looking custom shank is stimulation-capable.

“Ideal” should become an optimization question with declared objectives: usable recorded units, waveform separability, recovered evoked events, target/off-target response, energy, voltage demand, mechanical footprint, manufacturability, and robustness to placement. These objectives conflict. Report a Pareto set and the assumptions behind each candidate. Electrode-size optimization literature couples source signals with impedance and noise precisely because amplitude alone is insufficient [P6].

Fabrication-aware design should eventually include trace spacing, insulation thickness, contact recess, routing capacity, bank constraints, tip radius, alignment tolerance, yield assumptions, and source-supported material properties. These are constraints on candidate geometries, not quantities already recovered for every catalog device. Heating and chronic tissue response require additional models and relevant observations. A physically plausible shape, an electrically useful shape, and a manufacturable durable interface are different stages of evidence. Link them through the design record while leaving unavailable parameters explicit.

## 7. Design one coherent experimental experience

The entry point should offer concrete tasks: **Record twelve firing cells**, **Stimulate the cells**, and **Compare contact geometries**. Each should open an inspectable saved result immediately, with an editable setup derived from it. Detailed field and cell benches remain reachable as tools supporting the experiment.

Use four persistent views of one experiment:

- **Setup:** cells, source identities, poses, device geometry, contact roles, medium, return/reference, background drive, waveform, and estimated resources.
- **Observe:** scene, synchronized multichannel instrument, selected-cell voltage/current inspector, one biological timeline, and event raster.
- **Compare:** pinned baseline and variant with synchronized camera, time, axes, changed-input list, paired outcomes, and uncertainty.
- **Evidence:** exact numerical applicability, source provenance, limits, failures, and reproducible export/import.

The completed run must be immutable. Editing contacts or pulse settings creates a draft. The scene currently updates selection rings from pending controls while retaining the old result; this can visually mix a future setup with an already computed response. Show an explicit draft preview or keep the computed scene tied to its run. No pending selection should look as though it caused the currently displayed firing.

Contact inspection and contact roles should be separate actions. A click identifies a physical pad. Its inspector then shows supported recording, stimulating, return, or reference roles; waveform sign and actual current; exposed area; and provenance. The same contact ID should survive a trip through the designer, catalog, experiment, export, and comparison.

The instrument needs simultaneous channels, fixed/shared gain when comparing amplitudes, explicit µV/div and ms/div, a common cursor, pulse timing, and an event-centered zoom. Autoscaling every trace can make weak and strong signals look equally large. Mean subtraction should be a labeled display transform, not confused with a physical high-pass filter. Raw, referenced, filtered, artifact, and ideal-neural signals need distinct descriptors and units.

Clicking a raster event should pause around that event, select the source cell, show its soma and relevant branches, reveal its contribution at each retained contact, and align the stimulus. Later, the same view can explain why a real detector missed it: overlap, noise, blanking, clipping, or an insufficient waveform. This is where the visual experience can become a reasoning instrument.

Use one meaning for membrane color and a visible voltage legend throughout the electrical labs. Contact role and event validity should also use shape, labels, line style, or icons. Do not reintroduce whole-cell color categories that imply an unmodeled cell is electrically silent. Keep physical scale separate from a minimum display radius used for readability; allow inspection of both.

Accessibility should support the experiment itself: keyboard contact/cell/compartment selection, previous/next event, numeric readouts, an event table, accessible extrema and units, obvious focus, and reduced-motion defaults that stop automatic looping. A canvas label alone does not expose its data. On mobile, show a compact result and scene early, with setup controls in a deliberate panel rather than a long obstacle before the first observation. Preserve a useful tabular mode when WebGL is unavailable.

Failure recovery should retain the last completed run, identify the failed stage, keep diagnostic information, and offer a specific next action. A partial run must say which cells, time range, or channels are complete. Never silently drop cells or lower fidelity to make an animation continue.

## 8. Share infrastructure without rewriting the scientific kernels

The right architectural unit is an immutable experiment specification plus model adapters. Keep original cable, reduced cable, point/line conductor, finite disk, joint-pad field, and synthetic recording engines distinct. Each adapter declares supported geometry, units, boundary conditions, observables, numerical controls, and evidence. Reject incompatible combinations instead of silently substituting a simpler model.

A shared result envelope should include:

- Canonical experiment digest, schema version, source commit, engine version, source-model hashes, and asset hashes.
- Cell/device/contact identities, coordinate frames, transformations, medium, return/reference, and waveform definitions.
- Independent seeds for anatomy, physiological drive, drift, and per-contact instrument noise.
- Signal units, reference, sampling convention, shape, precision, binary byte order, and payload hashes.
- Event definitions, valid/silent/excluded/invalid states, numerical warnings, and exact evidence applicability.
- Delivered versus requested settings when compliance exists; visualization state stored separately.

The export should reopen the same result and meaning. The new lab currently exports data but lacks a replay-import workflow. Add schema validation, bounded allocations, content hashes, explicit migrations, and a readable explanation when an old engine or asset revision is unavailable. Never substitute a new fit silently. A model card and an experiment archive are different artifacts; both are needed.

Carry attribution and applicable license/source-use information with imported morphologies, fits, recordings, and device reference assets. Retain original upstream identifiers, retrieval/revision information, and transformations. An experiment export should identify its required source assets even when those assets cannot be redistributed inside the package. Separate access to an externally hosted reference from availability of a pinned reproducible local model; a disappearing URL should not silently erase the evidence trail.

Several performance improvements can preserve the physics exactly. The current worker is recreated for each run, defeating its internal caches. A retained worker session with job IDs, explicit cache keys, and bounded eviction can avoid repeated initialization. Worker termination remains the reliable cancel path until a yielding, cooperative execution scheduler is separately implemented and tested: a synchronous solver loop cannot process a new cancellation message mid-loop. Cache keys must cover every source and numerical input; a cell-ID-only conditioned-state key is safe only while those inputs remain fixed.

The static default-model import makes each worker expensive to load. Split model assets by identity and load the selected set. Decode large archives off the main thread, divide them into independently decodable time chunks, and load a first usable window before the entire replay. Cache static trace paths, axes, and raster marks; move only the cursor and selected readout during playback. Avoid continuously rendering an unchanged paused or hidden scene. Atlas v4 already supplies useful local patterns for dirty rendering, bounded caches, and level of detail.

Recording-only sweeps offer a particularly useful acceleration: retain full-precision transmembrane-current histories and reproject them through new lead fields when source dynamics are unchanged under the declared one-way coupling model. The current archive contains rounded Vm and aggregated recordings, so it does **not** already support exact reprojection. Add a current cache or validate a compressed basis with an explicit error budget. Changes to stimulation or any condition affecting membrane dynamics require a fresh solve.

Set performance budgets after establishing reference devices and browsers. Proposed targets include interactive controls and initial geometry before a large download; an initial replay chunk small enough for useful loading on a declared 10 Mbps connection; bounded main-thread tasks; stable playback at a measured 30 or 60 fps target; prompt cancellation acknowledgment; and bounded heap use across repeated runs. The approximately 159-second measured Node default computation is a development measurement, not a browser benchmark or a promised runtime.

## 9. Repair concrete defects before expanding claims

The following findings are actionable without waiting for new research. They are proposals from this audit; the review did not silently change these implementations.

| ID | Finding and affected surface | Consequence | Acceptance gate |
| --- | --- | --- | --- |
| F01 | Live cortical recorder shares RNG between source firing and channel noise | Adding a passive contact changes the neurons' event history, even with zero noise amplitude | Same biological inputs yield identical source events for any passive channel count, order, position, or noise setting |
| F02 | Live recorder adds a soma–sensor-distance waveform delay | Suggests a volume-conduction transit delay absent from the stated quasi-static source model | Remove the physical interpretation; any channel timing difference traces to spatial sources or declared filters |
| F03 | Reduced stimulation counts flagged extreme-voltage trajectories as recruitment | Invalid states can increase physiological response statistics | Keep diagnostic traces; exclude invalid states from valid recruitment and report their separate denominator |
| F04 | Peripheral stimulus markers enter the recording display independently of axonal events | Pulse display can be mistaken for neural recruitment | Zero stimulus adds no stimulus-driven events; zero neurons yields no neural events; pulse markers remain separate |
| F05 | Peripheral events depend on render timing | Frame rate changes recorded biological timing | Deterministic event schedule independent of rendering and catch-up policy |
| F06 | Duplicate duration-control IDs and malformed markup in `/sim` | A second control is not reliably bound | Unique IDs, correct labels, one authoritative duration state |
| F07 | Pending interface controls affect highlights beside completed data | A prospective contact selection can appear to explain an old response | Computed scene and plots remain bound to immutable run settings |
| F08 | Interface absent from discovery index; build verifier mainly covers old route | Flagship discoverability and release coverage lag the implementation | Search entry, built route/worker/data checks, supported-browser interaction gate |

F01 was reproduced independently with bounded probes. In one explicitly recorded configuration—20 cells, seed 1337, 400 ms, zero noise, no burst seeding, no modulation—one contact produced 30 source events and two produced 24. This is a behavioral defect in the synthetic recorder, not in the new active-cable laboratory.

Tests should target these scientific and user-visible invariants. Do not create a large suite that merely repeats implementation details or reruns costly calibration for every style change. Cheap contracts and route checks belong in routine CI; numerical fixture comparisons run when relevant kernels, protocols, or assets change; expensive independent and convergence studies remain versioned scientific jobs.

## 10. Experiments worth building

The platform can become distinctive by making difficult questions inspectable. Each experiment below has a controlled variable, a useful result, and a dependency that prevents premature claims.

| Experiment | What stays fixed / what changes | What it can reveal | Required next capability |
| --- | --- | --- | --- |
| Same-place contact comparison | Same cells, source history, center, orientation, reference; vary size or shape | Spatial averaging and ideal transfer effects without a location confound | Parameterized contact geometry and paired result view |
| Probe shadow | Same sources; no body, plane, finite body; vary front/back/tip position | Where a plane approximation fails and how the body changes observations | Independent finite-body conductor |
| Pulse counterfactual | Same conditioned state and drive; stimulation off/on | Added, suppressed, advanced, or delayed events | Paired runs and declared event matching |
| Why this cell? | Select one event and inspect connected compartments | Local forcing, ionic/axial currents, and candidate initiation paths | Linked compartment/event inspector and scoped propagation criteria |
| Evoked truth versus recovered spikes | Same neural response; vary acquisition and recovery | Which ground-truth modeled events survive clipping, blanking, filtering, and overlap | Delivery/acquisition model and blind detector |
| One source, many instruments | Same full-precision currents; vary reference, bandwidth, noise, gain | Recording trade-offs without changing physiology | Current cache and validated acquisition pipeline |
| Return-electrode comparison | Same target, delivered phase charge, and source state; vary returns | Focality, voltage demand, off-target effects, recovery | Supported explicit returns and delivered-current accounting |
| Reciprocity round trip | Reverse specified source/measurement roles | Executable field/recording consistency across geometry changes | Independent reference tests and explicit source integration |
| Numerical magnifier | Same physical experiment; refine selected field/cable/time approximations | Where conclusions are resolution-sensitive | Bounded refinement jobs and disagreement view |
| Manufacturing and placement tolerance | Same design; perturb documented uncertain dimensions/pose | Designs that remain useful away from a perfect placement | Evidence-based uncertainty and ensemble execution |
| Blind benchmark | Freeze held-out cells, placements, and waveforms | Whether improvements generalize beyond chosen demonstrations | Locked benchmark manifests and comparable metrics |
| Anatomy-to-experiment handoff | Preserve source identity and region context; create a declared local test | Coherent navigation from atlas to an electrically supported cell model | Shared IDs and capability-checked adapters |

A later design map can plot recovered recording performance against modeled stimulation selectivity, voltage/energy, footprint, and robustness. Show individual specimens and uncertainty before averaging. Keep numerical error, within-model variation, between-specimen variation, and model-form uncertainty separate. Arbitrarily jittering every conductance is not a defensible physiological population model.

A useful biological extension before a recurrent network is independently seeded excitatory/inhibitory conductance background, characterized against declared resting-voltage, variance, input-resistance, firing-rate, and interval-variation targets. It permits controlled state-dependent stimulation questions. A recurrent network can follow when a specific hypothesis requires connectivity, with explicit synaptic models, delays, and connection evidence. Increasing the cell count alone does not make the tissue model more biologically complete.

## 11. Ordered implementation program

The sequence below is dependency-based. Effort labels are relative; they are not calendar promises. Some independent field and acquisition research can proceed alongside product work, but each public claim must wait for its own gate.

| Stage | Deliverable | Relative effort | Exit condition |
| --- | --- | --- | --- |
| A. Integrity and orientation | F01–F10 corrections, draft/result separation, current capability map, searchable flagship, keyboard/reduced-motion pass | Small to medium | Direct confounds removed; prior results preserved; scoped tests and supported-browser checklist completed |
| B. First controlled design study | Same-place contact variants, pinned baseline, common axes/time, per-cell contributions, paired stimulation control, export/import | Medium | Reopened comparison reproduces inputs and outputs; changed-variable list is exact; no unsupported SNR/selectivity claim |
| C. Numerical reference for the integrated lab | Exact native comparison, relevant field/cable/time refinement, source-integration checks, held-out examples | Medium to large | Predeclared waveform/current/event gates reported, including failures and unresolved classifications |
| D. Finite body and geometry adapters | Tagged finite shank, explicit returns, designer/catalog adapter, front/back/tip placements | Large | Geometry contract matches renderer and solver; independent conductor and limiting-case tests pass within declared domain |
| E. Deliverable and observable signals | Measured interface parameter sets, compliance, reference, analog chain, clipping/recovery, ADC/noise, blind detection | Large | Commanded/delivered/ideal/acquired/detected outputs remain distinct; analytical and measured checks support chosen settings |
| F. Robust design search | Uncertainty ensembles, held-out cases, constrained multiobjective search, comparison report | Large/research | Rankings survive declared uncertainty; constraints and unmeasured assumptions are visible; external validation matches the intended claim |
| G. Broader biological and anatomical integration | Axon alternatives, conductance backgrounds, justified networks, atlas handoffs, additional implant classes | Research-dependent | Each added model has a source/protocol contract and its own numerical/experimental evidence |

The recommended immediate development target is **Stage B built on Stage A's integrity repairs**. It answers the user's central question—how electrode geometry changes what we can stimulate and record—within the present declared field approximation. Stage C should proceed on the exact same fixtures. This creates a stable benchmark for Stage D, rather than replacing the conductor and the interface simultaneously without a reference.

F11 must pass before the legacy mixed-size transfer matrix is reused in any geometry adapter or design study; its reuse is not an implicit shortcut around the independent field work.

Stage ordering does not permit a claim to outrun its biological prerequisites. In particular, stimulation-selectivity optimization remains conditional on the short-axon source model until an axonal family adequate for the intended claim is characterized. Move that part of Stage G ahead of any Stage F study claiming distal recruitment or delivered axonal propagation. A recording-only design study can have a different dependency graph.

A concrete first study would freeze the twelve source identities and poses, retain their baseline source currents, place one candidate contact at a fixed center/orientation, compare four sizes, and report per-cell ideal transfer and aggregate traces at shared gain. A separate paired stimulation study would hold initial state and drive fixed, compare off/on, and display event correspondence. Its report would state that detection, finite-body effects, and hardware deliverability are not yet evaluated. The user can learn something precise before all later stages exist.

## 12. Definition of a mature release

A mature integrated experiment should pass a complete user journey: open a sourced baseline; inspect every cell and pad; change one supported parameter; see requested versus computed settings; run or cancel without losing the previous result; compare synchronized outcomes; inspect failures and evidence; export; reopen; and reproduce its meaning. Browser checks must exercise built artifacts, including compressed replay loading, branch selection, worker completion/cancellation, resizing, navigation, WebGL failure, and downloads. A successful deployment is not a substitute for these checks.

A scientific release should answer three separate questions for each headline result: **What was calculated? How accurately was that calculation checked? What observation supports its relevance to real tissue or hardware?** The answers can have different confidence levels. A result remains valuable when the boundary is explicit.

A design release should name the device family, material, geometry revision, return/reference, delivered waveform, modeled source population, acquisition chain, objective, constraints, and uncertainty. It should identify which parameters are measured and which are hypothetical. It should show trade-offs and held-out performance rather than a universal winner.

A maintainable release should preserve prior engine and source hashes, publish a compact test/evidence manifest, retain historical failures, identify a rollback target, and avoid duplicate undocumented live engines. Review scientific changes at the appropriate layer. Infrastructure reuse should reduce accidental differences while allowing legitimate differences in physics to remain visible.

Maintain a component ownership map naming the responsible role for each numerical kernel, source import, evidence bundle, geometry adapter, and user-facing workflow. A numerical change should identify which downstream evidence it invalidates; a presentation change should identify which interaction checks apply. This keeps future human and AI contributors from editing a dormant engine, inheriting an unrelated validation result, or repeating already completed investigations.

The strongest future for this site is an environment where a beautiful observation leads naturally to a controlled question, a traceable calculation, an honest comparison, and an experiment someone else can reopen. The first integrated laboratory now gives that program a working foundation.
