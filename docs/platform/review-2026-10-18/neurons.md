# Neuron, membrane, recording, and numerical-integrity audit

Date: 2026-10-19. Scope: read-only examination of the current source and retained numerical reports. No new simulations, calibration sweeps, or browser interaction tests were performed for this audit. Paths below are relative to the repository root. Line references identify the inspected revision and may move after edits.

## Assessment

The platform has an unusually valuable foundation: source-identifiable human morphologies and fitted conductances; a cable implementation checked against native NEURON; explicit distinctions between polarization, threshold crossing, somatic waveform evidence, and propagation; and retained failed convergence results. The new twelve-cell interface is a meaningful integration of these parts. Its membrane animation is computed for every compartment, and the recording signal is projected from the same membrane currents through reciprocal finite-contact lead fields. It is substantially more than a visual combination of the older laboratories.

The next scientific milestone is a controlled, reproducible **model experiment** that can answer a narrow design question with numerical and model uncertainty attached. The current system does not establish an optimal electrode, biological selectivity, in-vivo firing statistics, or propagation along a complete human cortical axon. More cells and more elaborate anatomy would not by themselves close these gaps. Several inexpensive corrections to the older interactive models should precede additional features.

## Strong foundations to preserve

1. **Literal source models and honest identity.** `model-registry.js:8–37` records species, dataset, layer, temperature, provenance and limitations. The library contains fourteen human EAP specimens and two epilepsy-project basket-cell adaptations, not sixteen interchangeable generic cortical types. The latter pair uses the available reconstruction of the same specimen because the exact historical morphology revision is unavailable. This distinction is retained rather than silently declared an exact historical reproduction (`docs/cortex/CELL_LIBRARY.md:18–50`).

2. **Electrical geometry is more rigorous than a rendered SWC.** The Python exporters retain native Import3d area, axial resistance, section topology, taper and branch junctions; they preserve the upstream handling of disconnected fragments. `active-morphology.js` performs rigid placement rather than resizing cells to fit the scene. `active-cable.js:86–178` uses a tree solve, extracellular potential differences along edges, and solve-consistent outward membrane-current accounting. Zero-area junctions contribute no fictitious membrane current. Source channel temperature conventions, calcium update order, and dataset-specific inhibitory mechanism differences are retained in `active-channels.js` and `extra-channels.js`.

3. **Evidence is scoped.** `experiment-evidence.js` ties finite-field evidence to configuration and source identity. `response-analysis.js:77–101` explicitly declines to infer propagation from a local crossing or crossing order. This is scientifically valuable and should become a common platform contract rather than be weakened for a more dramatic display.

4. **The integrated recordings use the electrical state.** `interface-experiment.js:111–137` uses the finite-contact coefficients for forcing and reciprocal recording. Its current accounting is independently checked by the integration tests described in `INTERFACE_LABORATORY.md:32`. The displayed replay is sampled from the solved compartment voltages. Saved voltage quantization is disclosed; internal events and recorded signals are not manufactured from visual colors.

5. **Failures remain inspectable.** Both the original numerical-reliability report and the finite-field report retain failed resolution gates. The twelve-cell calibration preserves rejected candidates and the initially mesh-sensitive current choice. This is the right culture for a research tool.

## Concrete defects and immediate integrity improvements

### 1. Passive recording geometry changes the future neural event stream

Observed in the live recording engine: one `rand()` stream is used for neural event generation (`public/scripts/cortex-v2/engine.js:126–153`) and for every electrode's sample noise (`:208–218`). Adding an electrode consumes extra random numbers. The next neural step consequently receives a different sequence of random values. Presets restart the engine, but presets with different contact counts still diverge after the first noise block. Moving/adding/removing contacts clears trace buffers, not the neural RNG state (`main.js:79,87–88`; `engine.js:232–236`).

**Impact:** a geometry comparison can change both the measurement and the underlying source activity. This undermines the page's experiment even within its declared illustrative scope.

**Correction:** separate random streams for anatomy, neural drive, per-contact noise, and any drift; preferably retain an immutable source-event realization that all passive configurations observe. Acceptance: two configurations with identical biological settings and seed produce identical source events regardless of channel count, order, or passive positions; noise is repeatable per channel identity.

### 2. The illustrative recorder adds sensor-distance propagation delay

`engine.js:186–187` delays each waveform by `r / 600` milliseconds, implicitly assigning propagation at 600 µm/ms from neuron to sensor. Under the quasi-static volume-conductor approximation used elsewhere in the platform, this is not a physical extracellular transit time. Axonal membrane-current propagation can produce spatially changing waveform timing, but it must come from a spatial source, not a delay proportional to soma–sensor distance. The present engine has point event sources and templates.

**Correction:** remove this interpretation from a physical recording mode, or mark it explicitly as an illustrative nonphysical effect. A mechanistic mode should compute the evolving spatial source and instantaneous lead-field projection. Acceptance: a point-source reference has no artificial sensor-distance delay; any multichannel latency differences can be traced to source geometry or declared acquisition filters. LFPy provides an appropriate independent forward-model reference [S5].

### 3. Invalid reduced-model responses remain in headline recruitment results

The reduced cortical-stimulation membrane engine aborts only beyond ±3000 mV, while flagging |Vm| >200 mV (`src/lib/stimulation/membrane.js:72–79`). The result assembly still includes flagged cells in activation bins, counts, soma-distance extents and the first-event raster (`experiment.js:87–93`; `CorticalStimulationLab.jsx:189–216`). The UI warns about the flag, so this is a result-policy defect, not an undisclosed omission.

**Correction:** define and enforce a model-validity domain; count affected cells as invalid, preserve their diagnostic traces, and remove their responses from physiological denominators and extents. Do not substitute clipping. Acceptance: no out-of-domain trajectory can increase a valid recruitment count; valid, silent, excluded and invalid populations remain separately exported. A tighter limit should be justified against intended equations and use cases, not copied arbitrarily from the human solver.

### 4. Event semantics differ across laboratories

The original Cortex response report uses internal threshold events plus saved-frame waveform evidence; the new interface requires an internal −25 mV crossing, ≥0 mV peak within 3 ms, recovery below −40 mV within 20 ms and a refractory interval (`interface-experiment.js:153–168`). The reduced population model counts its first upward 0 mV crossing in soma/AIS/axon. The synthetic recording raster is an oracle selection of source events whose expected isolated peak exceeds 6 µV; it is correctly disclosed as neither a sorter nor a noisy-trace detector (`cortex-slab/index.astro:156,175`).

**Correction:** retain each model's raw measurements but introduce a shared event schema: local crossing, complete somatic waveform, censored waveform, axonal evidence, propagation assessment, and extracellular detection. Store criterion version, internal and saved sampling, origin and failure reason. A single word such as “spike” must not silently mean a different observable after moving between pages. Acceptance: raster labels and exports identify exactly which event class they contain; end-of-window censored events remain distinguishable from failures.

### 5. Peripheral timing and recording are rendering dependent

`src/pages/sim.astro:809–826` processes at most one due autonomous event per site per render update and records at `nowS`, not the scheduled `nextFire`. Delayed frames can change recorded timing. `applyStimToAxons` records stimulation markers during active rendering updates (`:833–855`), rather than constructing recordings from a defined physiological event process.

**Correction:** if this remains an illustration, explicitly keep proxy units and separate pulse markers from axonal events. If it becomes a simulation, move its state transitions to a deterministic biological-time engine with a defined catch-up policy and recording synthesis. Acceptance: identical scheduled inputs produce identical event times independent of rendering frame rate. Do not infer a physiological 5 Hz axonal ceiling from the present illustrative 200 ms refractory setting.

## The numerical evidence is strong in one sense and unresolved in another

Native-NEURON agreement asks whether two implementations solve the same discretized equations. Convergence asks whether conclusions stabilize as spatial and temporal approximation are refined. Biological validation asks whether those equations and parameters predict relevant observations. These are separate gates.

The original 141-run report reproduces all six historical extracellular spatial-threshold failures and fourteen of twenty-six waveform failures. Maximum selected-probe discrepancies remain 2.401 mV RMS and 32.20 mV peak (`NUMERICAL_RELIABILITY.md:28–32`). At a common 19 µA, 40/20/10 µm meshes produce no/local/no crossing, with no soma event; native NEURON reproduces this behavior (`:41–56`). This is evidence against calling it a simple JavaScript port bug, not evidence of convergence.

Finer follow-ups improve selected comparisons: some 5/2.5 µm and timestep-halving local-onset envelopes pass. However, fixed-current classifications still change near threshold, selected probes do not cover every membrane compartment, and the finest geometries have not all received independent dynamic comparisons. A 42-versus-43 µm placement difference at 40 µA has matched native behavior but does not establish one-micrometer biological selectivity (`NUMERICAL_RELIABILITY.md:68–110`).

The isolated finite-disk study likewise has thirty-six corrected native cases agreeing closely, while the initial local onset shifts by roughly 21.4–21.9% between 40 and 20 µm meshes. The 20-to-10 µm onset comparison passes its narrow gate; that does not remove the coarse failure. No somatic onset was found in the sampled amplitudes, which does not rule out narrow unsampled windows (`FINITE_RIGOR.md:11–19`). The documented correction of an erroneous native extracellular endpoint assignment is a useful example of why an independent harness also needs validation.

For the new twelve-cell presets, all final currents retain sustained complete events at 40 and 20 µm. Eleven final-current configurations retain sustained activity at half timestep; specimen 508378649's revised 2.0 nA setting has no half-timestep result. The original 1.6 nA setting had twelve complete events at 40 µm and one at 20 µm. Its replacement fixes the persistence criterion but does not prove timing or waveform convergence. Final comparisons include a 37.134 ms ordinal-event timing difference; counts and timing are not invariant (`INTERFACE_CELL_PRESETS.md:20–50`). These are calibrated demonstrations, not validated natural firing rates.

The new interface fixes 40 µm, dt 0.005 ms, saved sampling 0.1 ms, conditioning 100 ms and panel subdivision in its contract (`interface-experiment.js:24–27`). Fixed settings protect saved-preset consistency but cannot serve as a convergence argument. Its field-panel checks are useful internal evidence, and its exact configuration is explicitly described as independently unvalidated (`:174–178`). A disk result cannot certify the new multicontact problem.

**Recommended numerical work:** predeclare a small diagnostic matrix, then separate field discretization, cable discretization, time integration, output sampling and near-threshold event classification. Use fixed physical observation sites rather than comparing moving compartment centers as though they were identical. Investigate competing initiation sites and field variation over electrically long segments. Electrotonic-length criteria are useful starting points [S4], but are insufficient alone for sharply varying extracellular forcing. Derive any changed coupling consistently and retain the original solver as a reference. Do not adjust biophysics merely to make a convergence test pass.

## Biological validity: morphology, axon, channel and population scope

The largest stimulation limitation is the axon. The EAP exporter deliberately deletes the original reconstructed axon and installs two 30 × 1 µm sections. Its direction uses the last source axon section under a literal upstream PCA convention (`cortex-cell-library-model.py:26–50`; original exporter mirrors this). The epilepsy adaptation also uses two 30 µm sections with source-derived diameters. This is faithful reproduction of the published model, but it omits extensive axonal branching, passing fibers, myelination and nodes. Those structures can be central to extracellular recruitment; a nearby soma is not necessarily the activated anatomical element [S1, S3].

Preserve this model as the original human-fit reference. Add a separate stimulation-oriented model family with explicit provenance for full/repaired axons, myelination, terminal conditions and channel allocation. Do not silently graft a generic axon onto the original and call the result the same validated model. Adding axonal membrane changes load and can alter somatic firing, so every adaptation needs renewed passive and active characterization. The Aberra family is a useful comparative model, but its adult-human forms are adaptations of rat-derived reconstructions, not direct measured complete human neurons [S1].

The sixteen specimens are surgical temporal-cortical cells, mainly L2/L3, and the default twelve were selected partly for repeated-firing behavior under practical currents and manageable cost. They are a deliberately useful test set, not a representative census. The two epilepsy adaptations should remain separable in summaries. The library does not establish motor-cortex, somatosensory, deep-layer corticospinal, glial, molecular or disease-wide coverage. Excitatory/inhibitory labels do not implement excitatory/inhibitory network action without synapses (`population.js:191`; `CELL_LIBRARY.md:67–74`).

Matched morphology and fit identity is essential. Only atlas specimen 508378649 overlaps this imported fit collection. The other nine Allen atlas reconstructions, twelve H01 references and procedural DRG/spinal/thalamic cells cannot acquire measured firing behavior through a visual identity join. H01 is a remarkable temporal-cortex anatomical resource, but anatomy and connectivity alone do not supply channel kinetics or a matched active electrical fit [S7]. Preserve “electrophysiology unavailable” as data, not as a defect to hide.

Human fitted channels still contain mixed-species kinetics, section-type allocations, assumed reversal potentials and fixed source temperature. A model card should expose these in a concise provenance diagram. The existing fixed-34°C conventions are explicit in `active-channels.js:7–10`, `:49`, `:123` and `active-cable.js:12`; any future temperature slider must update relevant mechanisms and carry new validation, rather than alter only a displayed value.

## Ongoing firing, stimulation causality and recording detection need separate experiments

The new twelve-cell recording example produces ongoing activity through explicit soma current injection (`interface-experiment.js:129–148`). This is an appropriate deterministic patch-clamp-like test. It does not reproduce in-vivo high-conductance background states, synaptic correlations, adaptation history or network balance. Artificial 0–22 ms onset staggering separates events for inspection; it is not a measured distribution of spontaneous phases. A looped recording is playback of a finite solved window, not a continuation of biological dynamics.

A useful next mode is stochastic excitatory and inhibitory conductance drive, calibrated to declared targets for resting voltage, voltage variance, input resistance, rate and interspike-interval variation. Dynamic-clamp work provides a methodological basis [S2]; its animal-specific parameters should not be imported as human truth. This can precede a recurrent network. A later network requires explicit connection probabilities, delays, synaptic dynamics, input state and an uncertainty model. Twelve uncoupled cells do not become a functional cortical circuit through proximity.

Patch-style current also has a return-path assumption. By current conservation the summed outward membrane current of an injected isolated cable reflects the injected current; projecting it can include a DC/background-drive contribution. The current implementation correctly avoids adding injection a second time, but does not explicitly model the patch electrode and bath return. Its plot subtracts the trace mean (`CortexInterfaceLaboratory.jsx:45–46`), while raw exports retain the signal. Document the assumed return location, keep raw and processed signals, and distinguish subtracting a mean from a realistic acquisition high-pass filter. This is a modeling boundary, not evidence that the present KCL implementation is wrong.

The saved evoked example provides legitimate evidence of modeled evoked somatic events: no intracellular drive, two events after two pulses in specimen 601927090, and no event in its zero-current control (`INTERFACE_LABORATORY.md:20`). It does not establish propagation, a converged threshold, or biological selectivity. For combined ongoing/stimulation experiments, “more spikes” is an incomplete outcome: a pulse can advance a pending spike, suppress a later one, cause block, or change timing without changing count. Always compare identical initial states and background realizations with and without stimulation, and export added/lost events and phase shifts using a declared matching window. Scan for onset and loss windows; do not assume response is globally monotonic in current.

Propagation should be investigated with branch-resolved Vm, axial current and ionic current, post-stimulus evolution, and controlled perturbations of regenerative conductance or axial coupling. A traveling color gradient or crossing order alone cannot prove it, because the external field drives multiple locations directly. Define the evidence required before promoting a descriptive delay to a propagation claim. A full axon model is particularly important if the desired claim concerns spike delivery beyond the soma.

Recording needs its own ground-truth layer. The soma raster answers which model cells had declared soma events; it does not answer which were detectable from a pad. Preserve separate source events, membrane-current recordings, filtered/noisy acquisition, detection and sorting output. Add extracellular precision/recall, latency, overlap and source-attribution metrics after the acquisition and detector models exist. MEArec is a useful design reference for ground-truth recording benchmarks [S6]; waveform-template acceleration is suitable for some recording comparisons but cannot replace active membranes when asking how stimulation changes a cell.

Keep amplitude brackets and classification uncertainty, not merely bisection tolerance. Until passed, report exploratory resolution sensitivity |
| P1 | Paired geometry experiment | Hold cell identities, poses, drives and random realizations constant while varying pad size at the same center. | P2 | Stimulation-oriented axon family | Preserve original source models; introduce explicitly versioned full/repaired axon alternatives. | P2 | Background and acquisition models | Add independently seeded synaptic-conductance backgrounds with declared physiological targets; add explicit reference, bandwidth, noise and artifact handling. Demonstrate source-to-recording ground-truth metrics and sample-rate/anti-alias checks. The 0.1 ms output interval alone is not an acquisition model |
| P3 | Robust design studies and external validation | Evaluate contact choices across model, pose, conductivity, axon and background ensembles. Predefine performance measures and report Pareto trade-offs. Validate against held-out measurements matched in tissue/model/geometry/protocol; update claims only inside the validated domain |

The new conditioned-state cache currently keys by cell identity only (`interface-experiment.js:117–121`). This is safe under its fixed numerical/source contract; if temperature, fit, mesh, conditioning or initialization becomes adjustable, expand the cache key before exposing those controls. Likewise include all such settings and source hashes in saved-run fingerprints.

## High-value product and research directions

**A counterfactual experiment viewer.** Put baseline and intervention on the same time axis, with a difference trace, per-cell event correspondence and a control that toggles the same compartment between both states. This would make stimulation causality inspectable and turn the current vivid replay into a scientific reasoning instrument.

**A “why this cell?” inspector.** Show nearest membrane segment as well as soma distance; its local potential, axial potential difference, Vm, Na/K/Ca currents, event classification and provenance. It should explain what the solver observed without assigning an initiation site prematurely.

**A numerical magnifier.** Let an expert select a suspicious cell/branch and request a bounded refinement study whose progress and results are visible. Preserve the coarse run and display where classifications disagree. This is more useful than a global “high quality” setting with an implied accuracy guarantee.

**A recording–stimulation design map.** Plot recording distinguishability against modeled stimulation selectivity for the same set of contacts, under a declared source ensemble and electrical constraints. Larger pad area, distance, noise, artifact, allowed current and electrode impedance create competing objectives. An “ideal electrode” should mean a chosen point on documented trade-offs, not a universal winner. The present geometry mixes pad sizes and positions (`INTERFACE_LABORATORY.md:9`); a controlled equal-location size series is needed first.

**A model provenance ladder.** Let users move from measured morphology to source-fitted membrane, discretized simulation, acquisition and observed data while seeing which edges are measured, fitted, assumed or numerically verified. This supports integration of the atlas and device collection without silently upgrading an illustration into physiology.

**An ensemble that admits uncertainty.** Separate numerical error from within-model variation, between-specimen variation, parameter uncertainty and model-form uncertainty. Use physically justified priors or fitted parameter ensembles; arbitrary independent jitter of every conductance is not a physiological uncertainty model. Report individual specimens and sensitivity bounds before collapsing results to a mean. Conditional Wilson intervals in the older population page describe finite sampling under its assumptions, not uncertainty about anatomy or membrane validity.

**A scalable architecture with explicit fidelity boundaries.** Keep detailed active cells near the design question; use validated reduced/network sources for distant background where appropriate; keep source generation independent of lead-field projection and acquisition. LFPy and hybrid modeling work provide useful reference architectures [S5, S9]. Approximate or cached recordings must remain labeled and must not answer stimulation questions that require a fresh active solve.
