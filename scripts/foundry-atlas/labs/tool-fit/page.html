Method, provenance and reproducibility

Reference checks compare dimensions or operation roles against the named product or facility; the virtual checks describe the selected BuildTheSimulation experiment. Material permissions, ownership, facility access, full-stack interoperability, quality, yield and clinical suitability are never inferred. Every unspecified station/requirement pair stays unknown.

Input lengths are millimetres; feature widths are micrometres. For optical cases, the entire axis-aligned, centered rectangular footprint (including its corners) must fit on the sample. Rotation, sparse corners, bevel exclusion and coordinate placement are not modeled. Non-optical drawings are conceptual, not machine instructions.

Within each column a documented contradiction takes priority, followed by an unknown, then an in-bounds result. No probabilities or numerical fit scores are calculated. The JSON records all inputs, each reason and source, model version and dictionary revision; it is not a fabrication traveler.
