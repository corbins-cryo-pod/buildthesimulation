# Model / real tissue — Finger Pathway Atlas V3

50 source-attributed comparison plates, 2400 × 1640 px each. Left: actual V3 model. Right: a published scientific reference.

## Read first
The panels are independently magnified. They are not the same specimen, field, cell, or physical scale. Species, tissue, modality, and panel identity are labeled on every plate. Reference images have only been selected/cropped and resized, not generated or retouched. Original figure files are in reference_figures/.

## Model provenance
V3 geometry is unchanged. Model images were captured from its offline WebGL viewer with camera/visibility changes. Screen-only neurite visibility padding was on; optional modeled spines/boutons were off. Cortical cell membranes are generated around human light-microscopy traces, not EM-segmented surfaces. Model scale and source-cell limitations from the V3 model card remain in force.

## Contents
plates/: 50 full-size paired JPGs.
reference_figures/: 42 distinct original figure/gallery images, including uncropped context.
comparison_manifest.json: source bibliography, crop coordinates, original image hashes, reference links, and authored comparison notes.
model_render_provenance.json: actual V3 image hashes, camera states, model HTML hash, and display metadata.
